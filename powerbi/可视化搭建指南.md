# Power BI 可视化搭建指南

这份指南带你从空报表搭出完整的分析仪表板，成品可截图放进简历。

## 第 0 步：准备

1. 打开 Power BI Desktop →「获取数据」→ 选择「文本/CSV」或「MySQL 数据库」。
2. 导入 `data/raw/` 下的 5 个 CSV（或 MySQL `ecommerce` 库）。
3. 按 `数据模型.md` 建好关系、标记日期表。

## 第 1 步：页面结构与主题

建议分成 4 个报表页：

| 页面 | 内容 |
|---|---|
| **① 经营总览** | KPI 卡片 + 趋势折线 + 品类/渠道条形图 |
| **② 品类 & 产品** | 品类贡献度、畅销 TOP10、帕累托 |
| **③ 客户分析** | RFM 分层、复购率、地域分布 |
| **④ 明细下钻** | 可筛选的明细表（切片器 + 表/矩阵）|

## 第 2 步：经营总览页

**KPI 卡片（卡片视觉对象，每张卡放一个度量）：**
- 销售额、订单数、客户数、客单价、毛利率

**月度趋势（折线图）：**
- X 轴：`date_dim[month_name]`
- Y 轴：`[销售额]`
- 次要 Y 轴：`[同比增速]`（用面积图叠加）

**品类/渠道（条形图）：**
- 品类 → 销售额降序

**切片器（页面顶部）：**
- `date_dim[year]`、`products[category]`、`customers[province]`

## 第 3 步：品类 & 产品页

1. **品类贡献度矩阵**：行 = category，值 = 销售额、销量、毛利率、品类销售占比。
2. **畅销 TOP10**：条形图，Y 轴 = product_name，X 轴 = 销售额，按「TOP N」筛选 10。
3. **帕累托图**：条形图（销售额）+ 折线图（累计占比），X 轴共用 product_name。

## 第 4 步：客户分析页

1. **RFM 分层**：条形图，Y 轴 = segment，X 轴 = 客户数；图例可加会员等级。
2. **复购率卡片**：用 `[复购率]` 度量。
3. **地域分布**：
   - 地图（如需）用省份字段，但需要开启地图视觉对象；
   - 或用横向条形图展示省份销售额 TOP15。
4. **客户价值四象限**：散点图，X = `[订单数]`，Y = `[ARPU]`，图例 = 客户分层。

## 第 5 步：明细下钻页

1. 顶部放切片器：日期、品类、省份、渠道。
2. 放「矩阵」视觉对象：行 = category / sub_category，列 = year，值 = 销售额、销量。
3. 放「表」视觉对象：订单明细（order_id、product_name、quantity、subtotal、customer_id），
   设置「可视化 → 格式 → 交叉突出显示」方便筛选。

## 第 6 步：美化（让截图更有说服力）

- 统一主题色：建议用一个主色（如深蓝 `#2F5597`）+ 中性灰背景。
- 卡片加上边框和标题，字体统一。
- 图例、坐标轴标题都补全，避免「裸图」。
- 页面标题用「文本框」写明分析主题。

## 第 7 步：导出

- 每页截图（或「文件 → 导出 → PDF」）。
- 把截图放进 `docs/` 或直接用于简历作品集。
