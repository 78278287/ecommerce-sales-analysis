# Power BI 数据模型说明

## 1. 数据源

直接连接 `data/raw/` 下的 5 个 CSV（或连接 MySQL `ecommerce` 库的 5 张表）。

| 表 | 角色 | 主键 | 说明 |
|---|---|---|---|
| `customers` | 维度表 | customer_id | 客户信息 |
| `products` | 维度表 | product_id | 产品信息 |
| `orders` | 事实表 | order_id | 订单 |
| `order_items` | 事实表 | order_item_id | 订单明细（分析的主力事实表）|
| `date_dim` | 维度表 | date | 日期维度（用于时间智能）|

## 2. 星型模型关系

```
            date_dim ──(date)──── orders(order_time)
                                   │
                 customers ─(customer_id)─ orders
                                   │
                 products ─(product_id)─ order_items
                                   │
                              orders(order_id) ─ order_items
```

在 Power BI「模型」视图中建立如下 **1:N（一对多）** 关系，全部为单向筛选（维度 → 事实）：

| 关系 | 字段 | 方向 |
|---|---|---|
| `date_dim[date]` → `orders[order_time]` | 日期 | 1 : N |
| `customers[customer_id]` → `orders[customer_id]` | 客户 | 1 : N |
| `orders[order_id]` → `order_items[order_id]` | 订单 | 1 : N |
| `products[product_id]` → `order_items[product_id]` | 产品 | 1 : N |

> 注意：`order_time` 是 DATETIME。建议在 Power Query 中新增一列 `order_date = DATE(orders[order_time])`，
> 并让 `date_dim[date]` 关联 `orders[order_date]`，时间智能函数才能正常工作。

## 3. Power Query 预处理（可选）

进入「转换数据」，在 `orders` 表新增一个自定义列：

```m
// 在 orders 查询里新增列
order_date = Table.AddColumn(orders, "order_date", each DateTime.Date([order_time]), type date)
```

在 `order_items` 表新增成本列（用于毛利率）：

```m
// 合并 products 表取 unit_cost
= Table.NestedJoin(order_items, {"product_id"}, products, {"product_id"}, "products", JoinKind.LeftOuter)
= Table.ExpandTableColumn(#"上一个步骤", "products", {"unit_cost"}, {"unit_cost"})
```

## 4. 建模检查清单

- [ ] 事实表与维度表建立正确的关系，方向为「维度 → 事实」。
- [ ] `date_dim` 标记为「日期表」（选中该表 → 右键 → 标记为日期表）。
- [ ] 金额字段数据类型设为「十进制数」，数量设为「整数」。
- [ ] 隐藏不需要暴露给报表的外键列（如 `order_items.order_id`、`products.supplier`），保持字段整洁。
