# 项目技术说明

## 1. 项目定位

一个端到端的**电商数据分析项目**，完整覆盖数据生成 → 数据清洗(EDA) → 数据建模 → SQL 分析 → Python 分析 → Excel 报表 → Power BI 可视化 的流程，可作为数据分析师岗位的简历项目。

## 2. 技术栈与分工

| 技术 | 在项目中的作用 | 对应文件 |
|---|---|---|
| **Python** | 模拟数据生成、数据清洗(EDA)、ETL 入库、核心分析、Excel 自动化 | `scripts/` |
| **MySQL** | 数据仓库建模（星型模型）、SQL 分析查询 | `sql/` |
| **Excel** | 生成带图表的分析报表（openpyxl 自动化）| `excel/` |
| **Power BI** | 数据建模、DAX 度量、可视化仪表板 | `powerbi/` |

## 4. 数据模型（星型模型）

围绕 `orders` 与 `order_items` 两个事实表，连接 `customers`、`products`、`date_dim` 三个维度表：

```
         date_dim ── date ──> orders <── customer_id ── customers
                                  │
                                  └── order_id ──> order_items <── product_id ── products
```

- **事实表**：`orders`（订单级）、`order_items`（明细级，含 `subtotal` 金额）。
- **维度表**：`customers`（客户）、`products`（产品/品类）、`date_dim`（日期，支撑时间智能）。

## 5. 数据特点（刻意贴近真实业务）

- **脏数据**：原始数据包含缺失值、重复记录、异常值、脏格式、孤儿明细，用于完整演示数据清洗流程。
- **产品长尾**：销量服从重尾分布，少数爆款 + 大量长尾/死库存（~30% SKU 近零动销）。
- **客户复购差异**：下单次数服从重尾分布，复购率约 38%（贴近真实电商的 25~40% 区间）。

## 6. 运行步骤

### 6.1 生成数据（纯 Python，无需数据库）

```bash
pip install -r requirements.txt
python scripts/generate_data.py
```

### 6.2 数据清洗（EDA + 清洗）

```bash
python scripts/data_quality.py
```

产出：`data/processed/cleaned/` + 清洗报告 `data/processed/data_quality_report.md`。

### 6.3 分析（纯 Python，无需数据库）

```bash
python scripts/analysis.py
```

### 6.4 生成 Excel 报表

```bash
python scripts/excel_report.py
```

### 6.5 MySQL 部分（可选，需本地 MySQL）

1. 在 MySQL 中执行 `sql/01_create_tables.sql` 建库建表。
2. 用 `sql/02_load_data.sql`（`LOAD DATA INFILE`，需改路径与 FILE 权限）
   或 `python scripts/etl_load.py --user root --password 你的密码` 导入数据。
3. 执行 `sql/03_analysis_queries.sql` 查看分析结果。

### 6.6 Power BI 部分（需 Power BI Desktop）

按 `powerbi/` 目录下三份文档：导入 CSV/MySQL → 建关系 → 建度量 → 搭可视化。

## 8. 可复现性

- 数据生成使用固定随机种子（`SEED=42`），任意机器运行得到相同数据。
- 所有分析结果均可由脚本重新计算，避免「只有结论、没有过程」。
- 完整流水线：`generate_data.py → data_quality.py → analysis.py → excel_report.py`。
